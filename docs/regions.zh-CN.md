# 地区配置

**简体中文** | [English](regions.md)

安装前请机主明确确认**相机实际使用的国家或地区**及 B/C 选择，不根据语言、时区、销售地、ALLLANG 标签或路由器自动决定。尚未证实相机跨国使用时会自动切换配置，旅行前应重新核对。

下表来自**第一代 A7C 2.03 原厂 Backup 模板的离线分析**。B/C 分别选择不同网络模式的 NVRAM 配置，并非分别管理 2.4 和 5 GHz。编号以十进制列出，括号内是实际写入的十六进制字节。XR 是 Sony 固件内部代码，不是日本的 ISO 国家码。

| 地区／A7C 模板 | B → XR 修订 | C → XR 修订 | ZV-E10 2.02 状态 |
| --- | --- | --- | --- |
| 中国大陆，88601 CN1/CN2 | 2（`02`）→ 76 | 22（`16`）→ 143 | 热点、手机传图、经路由器远程拍摄已实测 |
| 日本，88600 J1 | 3（`03`）→ 77 | 23（`17`）→ 144 | 未测试 |
| 欧洲标签 CEC | 14（`0E`）→ 88 | 23（`17`）→ 144 | 未测试 |
| 北美标签，88600 UC2 | 18（`12`）→ 139 | 25（`19`）→ 146 | 未测试 |
| E38 | 17（`11`）→ 138 | 24（`18`）→ 145 | 未测试 |
| 88601 JE3 | 20（`14`）→ 141 | 22（`16`）→ 143 | 未测试 |
| ALLLANG／KR2／AP2／IN5，各型号存在的模板 | 14（`0E`）→ 88 | 23（`17`）→ 144 | 未测试；模板标签不直接等于实际使用国家 |
| 88601 AF1 | 9（`09`）→ 83 | 9（`09`）→ 83 | A7C 原厂关闭频带菜单，不作为解锁配置 |

实测 ZV-E10 修改前 B/C 为 `09/09`、菜单属性为 `00`，运行时报告 XR/83，只列出 2.4 GHz 信道 1–13。这是一台相机的记录，不是所有机器的通用原值；安装必须保存本机实际值。

中国大陆实验中，热点读到 XR/76，路由器连接读到 XR/143。两者均列出 2.4 GHz 1–13、5 GHz 36–64 和 149–165，以及 20/40/80 MHz 组合。这些读数尚不能证明发射功率、DFS/TPC、室内限制及整机型号核准。驱动列出信道也不等于获得在所有信道上发射的许可。

只有中国大陆组合具有 ZV-E10 功能实测。其余行是参考模板，普通安装流程遇到未测试地区应停止，不自动替换为中国大陆或 US/0。进一步地区测试属于单独研究，需要机主明确授权并核对当地要求。

采用 A7C 原厂配置不能直接证明修改后的 ZV-E10 获得当地无线型号核准。用户需自行核对实际使用地的规定，本项目不提供合规认定。
